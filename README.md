## Selected private projects

These repositories are private because they contain proprietary workflows, internal business logic, or operational integrations. I can still share what each product is designed to do:

- **SIMS — Smart Integrated Manufacturing System** — an integrated ERP and manufacturing-tracking platform connecting orders, BOMs, purchasing, inventory, quality, production, shipments, and payments.
- **production-tracker** — a live factory-floor system for tracking orders and production progress across sequential manufacturing stages.
- **clearhead-signal** — an AI-assisted XAUUSD signal engine combining real-time market analysis with a monitoring dashboard.
- **trading-journal** — a full-stack trading journal connecting a Next.js dashboard, Supabase, and MQL5 trade data for performance review.
- **email-ai-v5** — an IMAP-based AI agent with worker, dashboard, and administration tools for reading and responding to email workflows.
- **brn-approval** — an internal approval and email system built with Next.js and Supabase.
- **spl-app-2.0** — an overtime-authorization workflow with approval routing and automatic PDF document generation.
- **sales3-worker-bot** — a Telegram worker bot that supports internal operational tasks and automated notifications.
- **steven-ling** — a private distribution and backup repository for a Hermes AI agent profile.

Public case studies for selected products are available on my [portfolio](https://jayscreative.my.id/digital-products).
